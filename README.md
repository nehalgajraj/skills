# paperbooks

A simple implementation of tools for Claude models.

## Skills

This repository also includes a small sanitized skill pack under `skills/`:

- `attack` - adversarial multi-angle critique for plans, patches, PRs, and answers.
- `babysit` - GitHub PR merge-readiness workflow.
- `beforeafter` - ASCII before/after flow diagrams for bugs and behavior changes.
- `graph` - polished matplotlib PNG charts from metrics data.

The skill pack intentionally avoids local secrets, private repository defaults,
and generated artifacts.

# paperbooks

Small Claude tooling experiments plus a sanitized skill pack.

## Skill Pack

The reusable skills live under `skills/`:

| Skill | Purpose |
|---|---|
| `attack` | Run adversarial multi-angle critiques of plans, patches, PRs, architecture, and answers. |
| `babysit` | Drive a GitHub pull request toward merge readiness by checking CI, review state, conflicts, branch freshness, and blockers. |
| `beforeafter` | Explain behavior changes with side-by-side ASCII Before/After flow diagrams. |
| `graph` | Generate polished matplotlib PNG charts from metrics data, with simple and detailed modes. |

Each skill is stored as:

```text
skills/<name>/SKILL.md
```

Some skills include support files, such as `skills/graph/style.py` and example
chart scripts.

## Usage

Copy the skill directory you want into a compatible local skills folder, for
example:

```bash
cp -R skills/attack ~/.codex/skills/
cp -R skills/graph ~/.claude/skills/
```

Then invoke the skill by name in your agent session, such as `/attack`,
`/babysit`, `/beforeafter`, or `/graph`.

## Sanitization

The uploaded skills are sanitized for reuse:

- no local secrets;
- no private repository defaults;
- no generated bytecode or notebook outputs;
- generic examples instead of company-specific examples.

## Legacy Cleanup

The previous notebook entrypoint, legacy `tools/` folder, and agent prototype
folders were removed so the repository can move toward a cleaner source-only
skill-pack layout.
